# rebound

REBOUND: Readmission Prediction via Hospital Assessment of Risk with Medications

The PDF medsremote.pdf file contains the full protocol with stata code for the manuscript for "Validation of the readmission prediction risk tools relating to medication management"

The .do file "rebound.do" contains the original stata code with LaTex embedded.

Contact me (adam.livori@gh.org.au) if you need help.

For privacy reasons and as a condition of our Grampians Health and St John of God Human Research Ethics Committee approval, we have not shared the source data.
